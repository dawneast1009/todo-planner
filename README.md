# todo-planner

할 일과 일정을 한곳에 적어두는 개인용 웹앱입니다. 입력이 귀찮지 않은 것을 가장 우선합니다.

> 개발 중입니다. 아직 동작하는 버전은 없습니다.

## 만들 기능

- **한 줄 입력**: 입력창 하나에 한 줄 치면 저장. 날짜·시간·메모는 필요할 때만 붙임
- **오늘**: 오늘 해당하는 할 일·일정만 모아 보고 체크. 못 한 일은 다음 날로 자동 이월
- **예정 / 달력**: 앞으로의 항목을 날짜별로 확인. 날짜가 되면 자동으로 "오늘"에 올라옴
- **언젠가**: 날짜 없이 적은 항목은 따로 모아 둠
- **그룹**: 항목을 직접 만든 그룹으로 묶어 보기 (선택 사항)
- **D-day**: 중요 표시한 항목의 남은 날짜를 "오늘" 위쪽에 표시
- **학교 시간표·학사일정**: 나이스(NEIS) 교육정보 개방 포털 API로 가져와 보기 전용으로 표시
- **폰·PC 동기화**: 웹 기반이며 폰에서는 홈 화면에 추가해 앱처럼 사용

## 하지 않는 것

공부 시간 기록, 다른 사람과 공유, 앱스토어 출시, 외부 캘린더 연동, 통계.

## 비밀 키와 데이터

공개 레포이므로 API 인증키와 개인 할 일 데이터는 레포에 넣지 않습니다.
