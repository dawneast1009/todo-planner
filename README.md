# todo-planner

할 일과 일정을 한곳에 적어두는 개인용 웹앱입니다. 입력이 귀찮지 않은 것을 가장 우선합니다.

## 기능

- **한 줄 입력**: 입력창 하나에 한 줄 치면 저장돼요. 날짜·시간·그룹은 문장에서 알아서 읽어요.
  - `내일 3시 치과` → 내일 오후 3시 일정
  - `금요일까지 수학 과제 #수행평가` → 금요일 할 일, 수행평가 그룹
  - `12/5 영어 발표`, `다음주 월요일 상담`, `3일 뒤 택배`
  - `우유 사기` → 날짜가 없으면 "언젠가"에 저장
- **한 화면**: 시간표, 오늘, 예정, 언젠가, 달력이 한 화면에 다 있어요. PC에서는 달력이 오른쪽에 나란히 나와요.
- **오늘**: 오늘 해당하는 할 일·일정만 모아 보고 체크해요. 못 한 할 일은 다음 날로 자동 이월돼요.
- **예정 / 달력**: 앞으로의 항목을 날짜별로 봐요. 미리 적어둔 건 그 날이 되면 "오늘"에 올라와요.
- **메모**: 항목을 누르면 세부사항을 적을 수 있어요. 적지 않아도 돼요.
- **그룹**: 위쪽 칩을 누르면 그 그룹만 모아 봐요. 그룹을 고르지 않아도 저장돼요.
- **D-day**: "중요"로 표시한 항목은 맨 위에 남은 날짜가 떠요. 학사일정에도 켤 수 있어요.
- **학교 시간표·학사일정**: 나이스(NEIS) 공개 API로 주간 시간표와 학사일정을 보기 전용으로 보여줘요.
- **폰·PC 동기화**: Firebase로 동기화해요. 폰에서는 홈 화면에 추가하면 앱처럼 쓸 수 있어요.
- **백업**: JSON으로 내보내고, 그 파일로 다시 덮어써서 복원할 수 있어요.

## 시작하기

```sh
npm install
npm run dev
```

Firebase 연결, 나이스 인증키, 배포 방법은 [docs/setup.md](docs/setup.md)에 있어요.
